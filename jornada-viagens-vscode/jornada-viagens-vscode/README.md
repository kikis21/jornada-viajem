# Jornada Viagens — projeto final

Site responsivo em HTML e CSS, preparado para abrir e editar no VS Code.

## Estrutura

- `index.html` — estrutura da página inicial
- `css/style.css` — estilos responsivos
- `img/` — imagens, ícones e favicon

## Como executar

1. Extraia o ZIP para uma pasta.
2. Abra a pasta `jornada-viagens-vscode` no VS Code (`Arquivo > Abrir Pasta`).
3. Abra `index.html` no navegador ou use a extensão **Live Server** e clique em **Go Live**.

O layout é mobile first e possui breakpoints para tablet, notebook e desktop. A fonte Montserrat é carregada do Google Fonts quando há conexão; o restante dos recursos visuais está incluído localmente.
